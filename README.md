# Khalil Bou Khalil - AI Engineer Portfolio

React and Vite portfolio for Khalil Bou Khalil, a Junior AI Engineer focused on LLM applications, AI agents, RAG and machine learning.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The production build uses the `/Portfolio/` base path for GitHub Pages. Professional content is maintained in `src/data/portfolio.js`, and the public CV is served from `public/Khalil_Bou_Khalil_CV.pdf`.
